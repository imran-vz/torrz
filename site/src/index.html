Open source, for macOS

A BitTorrent client where every click is a command.

Torrz is a desktop torrent client written in Rust. Every button in the window has a matching torrz command, so anything you can do with the mouse, you can also put in a script.

How it works

Every button is a command

Clicking Pause, pressing Space, choosing Pause in the ⌘K palette and running torrz pause selected all end up in the same function. The terminal has no separate code path, so it can't fall behind the window.

In the windowIn the terminal
Pause the selectiontorrz pause selected
Show only downloadingtorrz ui filter downloading
Open the Peers tabtorrz ui tab peers
Add the best trackerstorrz trackers add 3
Copy the magnet linktorrz ui copy magnet 3
Set speed limitstorrz limit --down 12M

The window shows you the command for what you just did.

Each row in the palette lists its command, and ⌘C copies it. The Log tab keeps everything that ran, clicked or typed, as the exact command line along with what came back.

  • Add a control without a command and a test fails.
  • Commands answer in JSON when you ask, and exit non-zero when something goes wrong.
  • torrz ui state dumps everything the window is showing.
Features

What it does

The things you'd expect from a torrent client, each with its own command.

Command palette

Press ⌘K and start typing. Actions and torrents show up with their commands next to them, and ⌘C copies the one you're on.

Magnet links

Click a magnet link in your browser and Torrz opens with the Add dialog filled in. If another client has claimed magnet links, one menu item asks macOS to send them to Torrz instead.

Watched folder

Pick a folder and Torrz adds any .torrent file that appears in it, and can move each one to the Trash afterwards. Files already in the folder are left alone.

Faster public trackers

Torrz takes newTrackon's list of trackers with good uptime, times each one from your connection, and adds the 20 quickest. It never adds public trackers to a private torrent.

Peers

Each peer's live download and upload speed, whether it's on TCP or uTP, and a bar that shows which peers your data is actually coming from.

Piece map

Pieces are drawn as dithered cells, in the same style as the icon. A cell that's partly downloaded flickers while data is arriving.

librqbit underneath

The engine is librqbit, so you get DHT, peer exchange, uTP, UDP trackers, private torrents, per-file selection, fast resume, speed limits and UPnP.

JSON out

Add --json to any command and pipe it into jq. A script can also drive the window itself: select a row, open a tab, press a dialog's button.

Demo mode

torrz open --demo starts twelve fake torrents. Nothing goes over the network or onto your disk, so you can click around without consequences.

Terminal

Run it from another terminal

While Torrz is open, the torrz command talks to it over a local socket. You can add and pause torrents, choose files, change speed limits, or switch the window's tabs. Answers come back as plain text, or as JSON with --json.

Read the CLI reference →

~ zsh
$ torrz add 'magnet:?xt=urn:btih:…' --category "Linux ISOs"
added #3
$ torrz trackers add 3
added 20 trackers to 1 torrent
$ torrz limit --down 12M --up none
limits: down 12.0 MB/s, up unlimited
$ torrz list --json | jq -r '.data[] | select(.state == "seeding") | .name'
Fedora-Workstation-Live-43-1.6.iso
debian-13.2.0-arm64-DVD-1.iso
$ torrz ui tab peers   # the window follows
Install

Install

There's no download yet, so you build it from source. You need Rust, and Xcode for the Mac app.

Get the code

Clone the repository.

git clone https://github.com/imran-vz/torrz
cd torrz

Build the app

This makes dist/Torrz.app, which handles magnet links.

scripts/make-app.sh
cp -R dist/Torrz.app /Applications/

Open it

Or start the demo if you'd rather look around first.

open /Applications/Torrz.app
torrz open --demo

Torrz is early. It downloads and seeds real torrents on macOS. Linux should build, but nobody has tried it yet, and on Windows the command line doesn't work. The getting started guide has the details.

Help build it

Bug reports and pull requests are welcome. There's one house rule: if you add a button, add its command too.
